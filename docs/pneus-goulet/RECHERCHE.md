Intensités : DESIGN_VARIANCE 8, MOTION_INTENSITY 7, VISUAL_DENSITY 4. CSS natif et React dans le projet existant ; aucune imitation de design system officiel.

## Référence de formulaire

[Site de référence consulté](https://garage.vision-tech-ai.com/) : marque, année, modèle, finition, service, nom, téléphone, courriel, date, heure et notes. Son formulaire annonce une réservation et une confirmation automatique.

La page Goulet conserve les renseignements du véhicule et les coordonnées, ajoute la dimension des pneus et adapte la conversion au fonctionnement sans rendez-vous. Modèle et finition sont saisis librement afin de ne pas présenter un catalogue de véhicules incomplet comme une base exhaustive. La date et l’heure ne sont pas demandées puisqu’aucune réservation n’est faite.

Le formulaire valide les champs requis puis prépare un lien courriel vers pneusgoulet@hotmail.com. Le visiteur ouvre sa messagerie et envoie lui-même le message. Aucun serveur d’envoi, calendrier ou CRM n’est raccordé. Aucun succès d’envoi fictif n’est affiché. Une intégration d’envoi direct nécessitera de choisir et configurer le service de réception du garage.

## Livraison technique

- Aperçu local : http://127.0.0.1:4320/goulet/
- Entrée séparée : goulet/index.html ; l’atelier existant demeure à la racine.
- Production : npm run build génère les deux entrées.
- Prévisualisation : npm run dev -- --port 4320, puis ouvrir /goulet/.
- Nouvelle dépendance : @fontsource/rye (police locale, aucune requête Google Fonts). Le lockfile a été mis à jour par npm install uniquement.
- La page de travail reste en noindex. Aucun déploiement ou changement du domaine de l’entreprise n’a été effectué.
- Avant lancement public : confirmer la réception du courriel et le numéro secondaire, valider les droits des images d’inspiration, choisir le domaine final, adapter les métadonnées sociales en URLs absolues, retirer noindex après validation et prévoir les redirections des anciennes pages.
